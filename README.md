# 🕷️ Spider-Man Web Fanpage

> **Tugas Akhir Submission — Belajar Dasar Pemrograman Web**  
> Diselenggarakan oleh **Dicoding Indonesia**

Website sederhana bertema superhero Spider-Man (Peter Parker) yang dibangun dengan standar HTML5 Semantik dan CSS3 murni tanpa framework maupun JavaScript.

---

## 🚀 Fitur Utama

- **Semantic HTML5 Elements**: Menggunakan elemen standar `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, dan `<footer>` untuk struktur dokumen yang bersih dan mudah diakses.
- **Responsive Layout (Flexbox)**: Desain responsif yang menyesuaikan tampilan layar desktop, tablet, dan smartphone dengan CSS Flexbox dan Media Queries (768px & 500px).
- **Pure CSS Micro-Interactions**: Efek interaktif dinamis seperti hover glow, hover elevation card, dan animasi underline navigasi.
- **Custom Comic Typography**: Menggunakan Google Fonts (*Bangers*, *Oswald*, *Montserrat*) untuk memberikan sentuhan gaya buku komik.
